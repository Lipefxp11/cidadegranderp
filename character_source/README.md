# Texturas BCG V027 R2

A textura masculina preservada usa skin 24/wbdyg1. A nova textura feminina usa skin 12/bfyri. Ambas são atlas de 512 × 1024 pixels e estão no banco DXT1 bcgskin, instalado e verificado pelo BootConfig. Os modelos/esqueletos continuam os da base. O arquivo PNG feminino foi gerado para esta atualização; não veio de Reduto. Mantenha o atlas masculino preservado, que já conectou na V026.
